# 🔥 PrivEsc-Automation 🔥

🚀 **🚀 Automated Privilege Escalation Tool for identifying and analyzing security misconfigurations.**

## ⚡ Overview
PrivEsc-Automation is a powerful privilege escalation tool designed to automate the process of finding and exploiting misconfigured binaries that allow privilege escalation. It supports SUID, sudo rules, and Linux capabilities vulnerabilities.

## 🔍 Features
- ✅ Automates Privilege Escalation from misconfigured binaries
- ✅ Integrates LinPEAS for automated security misconfiguration detection  
- ✅ Leverages **GTFOBins** techniques for privilege escalation
- ✅ Supports **SUID, sudo, and capabilities-based exploits**
- ✅ **Lightweight and Fast Execution**
- ✅ Useful for **CTF Challenges & Red Teaming**

## 🚀 Installation & Usage

### 💍 Clone the Repository
```sh
git clone https://github.com/your-username/PrivEsc-Automation.git
cd PrivEsc-Automation
```

### ▶️ Run the Script
```sh
python3 privesc.py
```

## 🔧 Requirements
- 📌 Python 3
- 📌 Linux Environment

## 📉 Privilege Escalation Techniques
- 🔹 **SUID Binaries** – Exploits misconfigured binaries with SUID permissions
- 🔹 **Sudo Binaries** – Finds binaries that allow sudo execution without a password
- 🔹 **Capabilities Exploits** – Detects and abuses Linux capabilities for privilege escalation
- 🔹 **GTFOBins Integration** – Uses known privilege escalation methods from GTFOBins
